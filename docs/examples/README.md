# Examples and screenshots

The repository includes visual examples so users can see the human-facing outputs before running a study. Screenshots demonstrate layout and information depth; they are not proof of audience validity or campaign performance.

## Reusable audience panel

![Populated audience segments](../screenshots/audience-panel-segments.png)

This populated Slop Sentry example shows three audience segments with descriptions, primary needs, objections, and creative implications. It demonstrates what the human-readable panel contains. It does not turn the displayed profiles into human respondents or claim population weights.

## Attention evidence

![Attention heatmap](../screenshots/dashboard-visual-evidence.png)

Attention overlays show whether visual emphasis aligns with a declared target. They are not eye tracking and cannot change the creative ranking.

## Example policy

- Use fictional or InnovAItion Partners-owned examples unless another example is explicitly authorized.
- Do not invent creative rosters from strategy fragments.
- Do not publish private source data or person-level evidence.
- Label missing and omitted evidence honestly.
- Bind every screenshot to the current shipped renderer before release.

For every generated file, see [Outputs and files](../reference/outputs-and-files.md).
